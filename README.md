Overview: MindCheck is an interactive digital emotional check-in prototype designed to encourage young people to pause and reflect on their emotional wellbeing. Developed using HTML, CSS and JavaScript, the prototype provides a simple interface where users can engage with questions about their wellbeing.
The project explores how digital technology can support emotional self-reflection through user-centred design. MindCheck is intended for self-reflection and general wellbeing awareness, rather than diagnosing or treating mental health conditions.

Technologies Used:
HTML: Webpages Structure
CSS: Visual design, layout, typography, styling etc
JavaScript: Adds overall interactivity and functionality

Purpose:
The purpose of this assignment was to explore how coding and interface design can be used to create a digital experience that encourages young people to engage with their emotional wellbeing.

Disclaimer:
MindCheck is a prototype for self-reflection purposes only. It is NOT a diagnostic tool nor does it replace professional mental health support.
